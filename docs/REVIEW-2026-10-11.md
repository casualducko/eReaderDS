# Overnight code review, 2026-10-11

Read-only review of every Lua module and the shell scripts. Nothing could be run
(no LÖVE on the review machine), so fixes were limited to ones checked by
reading plus `luajit -bl` (syntax, no stray globals). **Test on a device before
releasing.** Fixes are on branch `overnight-review`, not merged or pushed.

## Fixed
- Magnifier nil crash when opening a book; `fit_image` GPU state and leaks; JPEG fill byte (main.lua, comic.lua).
- Dictionary compound split; empty highlights file name; half-added sync server; backup list with a bad month.
- Parser hardening: zip entries over 192 MB refused, dict entries capped at 1 MB, `&#nan;` entity, chapter cache freed on close.
- Net: header caps, Calibre buffer cap, Calibre books limited to epub/txt, 1 byte to 300 MB, fitting the free space.
- Receiver rejects cross-site POSTs; backup file-count off by one; `install.sh` copies `libs.rocknix`; release build checks Lua syntax.
- Updater download is checked against GitHub's SHA-256 for the asset.
- Comic page that kills the page thread is marked failed instead of looping.
- Sync push: only a 2xx counts as healthy. Plain `http://` sync servers outside the home network are refused.
- Shell commands quote paths with `app/shq.lua`.
- `.bak` copies are written aside and renamed.
- What's New text, a stale font sample and the closed book's cover are released.
- Less garbage per frame: shared quad (comic, magnifier), reused page-flip vertices, cached Calibre server list.
- Backup dialog says the backup holds saved logins (they stay in backups on purpose).
- Ten Windows-1252 characters were deleted from text; now kept.
- Dead code and small things (duplicate setFont, unused locals, toast line width, uptime, tap after an ignored slide).

## Left
- Updater signature (needs a signing key). The `.update-test` file and `READER_FAKE_UPDATE_URL` hooks stay (needed for testing on Android).
- Android CA bundle sits on shared storage; build scripts download dependencies without checksums.
- Per-frame garbage still open: `draw_book_art` curves, theme editor gradients, `Store.get_*` in draw.
- Quadratic regexes in book.lua OPF/CSS parsing on hostile input; layout `hard_split` on very long words.
- Duplicated helpers (dirent FFI, mkdir_p, df parsing, atomic write) could share sysfs.lua.
- main.lua is at the 200-local limit: moving `stick_*`, `STICK_*`, `raw_logged` into one table frees several.
- Smaller ones from the reviews: lid-failed flag persisted in settings, search coroutine leaks a chapter on error, fonts picker `.part` leftovers, idle dim during transfers, Calibre sends no error reply, launcher edge cases, `math.random` unseeded in threads, `/info` with non-UTF-8 names.
