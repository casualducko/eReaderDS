# Overnight code review, 2026-10-11

Read-only review of every Lua module and the shell scripts. Nothing could be run
(no LÖVE on the review machine), so fixes were limited to ones checked by
reading plus `luajit -bl` (syntax, no stray globals). **Test on a device before
releasing.** Fixes are on branch `overnight-review`, not merged or pushed.

## Fixed
- Opening a book while the magnifier was still loading crashed (`app.zoom.img` nil).
- `app.fit_image` could leave the GPU draw state pushed and leak on a GPU error.
- JPEG header scan skipped markers after a 0xFF fill byte (main.lua and comic.lua).
- Dictionary compound split on every byte 226 (broke curly quotes); now splits on dashes.
- Highlights export file named `.md` when a title was all stripped characters.
- Adding your own sync server saved the address even if the name step was cancelled.
- Backup list crashed on a hand-edited manifest with a bad month.
- zip.lua refuses entries over 192 MB (deflate bombs); dict entries capped at 1 MB.
- `&#nan;` entity could throw in the HTML parser; chapter cache freed on book close.
- Net: header line/count caps; Calibre receive buffer cap; backup zip file-count off by one.
- Receiver rejects cross-site POSTs (browser `Origin` not matching `Host`).
- `install.sh` now copies `runtime/libs.rocknix`; `build-release.sh` checks Lua syntax.
- Dead code: duplicate setFont, unused locals, unreachable comic branch; toast left line width 2.

## Not fixed: worth doing (needs device testing or a design choice)
- Updater: the download is now checked against GitHub's SHA-256 for the asset (done, later). There is still no signature, so a compromised GitHub account could publish a bad release. The `.update-test` file and `READER_FAKE_UPDATE_URL` hooks remain.
- Comic page thread death can loop forever re-sending a page that kills it (main.lua `comic_poll`).
- Sync push: only a 2xx now counts as healthy (done, later).
- Calibre: books must be epub/txt, 1 byte to 300 MB and fit the free space, else the connection is dropped (done, later).
- Shell commands: paths now go through `app/shq.lua` single-quoting (done, later).
- Credentials (calibre.json, kosync key) are included in backups; plain-http sync server: now refused unless it's on the home network (done, later).
- Android CA bundle on shared storage; build scripts download deps without checksums.
- `.bak` copies are non-atomic and only made for frequent files.
- Font picker sample fonts, last book cover, `look.fonts`, `app.wn` kept alive after leaving their screens.
- Per-frame garbage: Bézier/triangulate in `draw_book_art`, `blit_turning` vertex tables, theme editor gradients, quads created every draw, `Store.get_*` in draw, `calibre.json` re-read 3x per redraw.
- Quadratic regexes in book.lua OPF/CSS parsing on hostile input; layout `hard_split` on very long words; CP1252 map in layout.lua missing 10 characters.
- Duplicated helpers (dirent FFI, mkdir_p, df parsing, atomic write) could share sysfs.lua.
- main.lua is at the 200-local limit: moving `stick_*`, `STICK_*`, `raw_logged` into one table frees several.
